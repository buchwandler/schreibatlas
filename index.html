    Was dieses MVP zeigt

    Das MVP ist absichtlich ohne Backend und ohne Framework gebaut. Es kann direkt per GitHub Pages ausgeliefert werden. Daten, UI und Lizenzen liegen gemeinsam im Repository.

    • vollständiges A–Z / a–z Alphabet in der Oberfläche,
    • modellbezogene Buchstabenansicht,
    • Schreibanweisungen pro Buchstabe,
    • Seitenvergleich mehrerer Schriftmodelle,
    • Quellen- und Prüfstatus im Datenmodell,
    • GitHub-Pages-Deployment via GitHub Actions.

    Nächster Datenausbau

    Die Demo-Modelle sollten durch echte, belegte Schriftmodelle ersetzt werden. Besonders wichtig sind SVG-Strokepfade, Quellenangaben pro Zeichen, Varianten und ein Review-Status.
